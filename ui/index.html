بلک‌اوت — رله‌ی شخصی

وقتی اینترنت تقریباً قطع است، رله از مسیرِ گوگل + کلادفلر تونل می‌زند. یک‌بار طبقِ مراحل بساز، بعد آن را به‌عنوانِ یک VPNِ جدا روشن کن (جدا از لیستِ سرورها).

مراحلِ پایین را انجام بده

یک کلیدِ امن بساز — هر رشته‌ای (این رمزِ بینِ گوگل و کلادفلرِ توست):
2
Cloudflare Worker بساز — برو به dash.cloudflare.com → Workers & Pages → Create → Worker. یک اسم بده؛ آدرسش می‌شود مثلِ myrelay.username.workers.dev. آن آدرس را اینجا بگذار:
کدِ Worker (این را داخلِ ادیتور پیست کن → Deploy)
…
3
Google Apps Script بساز — برو به script.google.com → New project. این کدِ آماده (با کلید و آدرسِ خودت پُر شده) را کپی و پیست کن:
کدِ Code.gs (آماده)
…
سپس بالا سمتِ راست Deploy → New deployment → کنارِ «Select type» چرخ‌دنده → Web app → «Who has access» = Anyone → Deploy.
گوگل یک هشدار نشان می‌دهد (چون اپِ شخصیِ خودت است، کاملاً امن است). این مراحل را دنبال کن:
  1. «Authorize access» → اکانتِ جیمیلت را انتخاب کن.
  2. صفحه‌ی «Google hasn't verified this app» → پایین «Advanced» را بزن.
  3. «Go to … (unsafe)» را بزن.
  4. در آخر «Continue» / «Allow» را بزن تا اجازه بدهی.
حالا آدرسی مثلِ …/macros/s/AKfyc…/exec می‌دهد؛ قسمتِ AKfyc… را اینجا بگذار:
4
